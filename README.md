# TS Academy Capstone Project - Group 17

## About The Project

This is a Planetary Information Website where users can search for a planet by name and view its details, fetched from an API, in a Profile Section below the Search Bar.

Below that, a "Planetary Facts At A Glance" table lists the planets grouped by category:
i. Terrestrial Planets
ii. Jovian Planets(Gas Giants and Ice Giants) and
iii. Dwarf Planets

## Features

### 1. Planet Search:

Users can type a planet's name in the Search Bar and click search to fetch it's data from the API

### 2. Profile Section

### 3. Error Message :

If the search does not match one of the nine planets listed in the table, "No Resuls Found" error message would be shown instead of the profile section holding the planet information

### 4. Planetary Facts At A Glance:

It's a table listing the planet's name, mass and diameter, grouped by category.

### 5. Light/Dark Mode:

Users can switch themes with the toggle opposite the planet logo, it's labelled "Dark" in light mode and "Light" in dark mode.

### 6. Responsive Design:

The layout adapts to mobile, tablet and desktop screens.
